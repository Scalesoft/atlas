# Dokumentace editoru (Atlas.Markdown)

Dokumenty editoru, převzaté i s historií z jeho dřívějšího samostatného repozitáře. Popisují balíček
[`src/Atlas.Markdown`](../../src/Atlas.Markdown) a knihovnu [`src/Atlas.Markdown.Sync`](../../src/Atlas.Markdown.Sync).

- Starší dokumenty mohou zmiňovat původní cestu `packages/markdown`, dnes `src/Atlas.Markdown`. Datované zprávy a audity se nepřepisují.
- Galerie, Playwright sada a referenční server editoru zůstaly ve starém repozitáři; odkazy na ně jsou historické a v tomto repozitáři nevedou nikam.
- Commity, na které dokumenty odkazují, patří původnímu repozitáři editoru; v tomto repozitáři je historie editoru zachovaná v `src/Atlas.Markdown`.
