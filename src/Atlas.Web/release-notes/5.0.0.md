### Hlavně
Atlas je open source.
- **Veřejný repozitář:** zdrojový kód Atlasu je veřejně dostupný a každý si ho může prohlédnout, spustit a upravit.
- **Příspěvky vítány:** opravy, nápady i nové funkce můžete poslat přímo do repozitáře.
- **Pro uživatele beze změny:** Atlas funguje stejně jako dosud; stránky, tabule, kontakty i nastavení zůstávají, jak jsou.
