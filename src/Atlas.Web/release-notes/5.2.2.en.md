*27 November 2026*

### Fixes
- **Person card:** the "Umí" (skills) row no longer sits on the edge of the card, and long topics are shortened instead of stretching the card.
- **Saved:** the confirmation sits right next to the edit date instead of far to the right, and after a moment it fades to a quiet icon. It shows in full only while the page is saving, you are offline, saving is paused, or saving failed.
- **Search:** the text in search is larger, above all the query in the field and the result titles.
- **Deleted pages:** when a page no longer exists or you may not read it, Atlas does not keep asking for it when a tab wakes up or the connection returns.

### For AI and MCP
- **`atlas_get_syntax` tool:** an agent connected over MCP can ask for the exact way to write every page component (info box, table, formula, diagram, contact, chart…), with options and examples, and learn which ones can only be read.
- **Info boxes and other components:** a write that does not recognise a component no longer leaves its source as text on the page. A box written on one line (`> [!WARNING] text`) is read correctly and the agent gets a warning with the exact form; other wrong forms get a warning or a clear error.
