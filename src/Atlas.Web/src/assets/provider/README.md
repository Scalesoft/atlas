# Provider marks

These unmodified SVG marks identify the provider choices in AI settings. They are bundled locally so the settings page makes no image requests to the providers.

- `openai.svg`: OpenAI's developer-site favicon, [source](https://developers.openai.com/favicon.svg), retrieved 2026-10-06. OpenAI name and logo are OpenAI trademarks; see its [brand guidelines](https://openai.com/brand/).
- `claude.svg`: Claude's site favicon, [source](https://claude.com/favicon.svg), retrieved 2026-10-06. Claude is an Anthropic product and mark.

Use these only to identify the matching provider option. `AiGlyph` remains the mark for AI actions and results; other providers continue to use the normal type icons.
